### 3) CT-MRI Image Transformation AI Model
- 한 줄 요약: 비정합 CT-MRI 영상 변환에서 구조 보존과 디테일 복원을 강화한 시스템.
- **Role** CycleGAN + Perceptual Loss 설계, ResNet Generator 구현

- **Tech** CycleGAN, ResNet, PatchGAN, VGG Perceptual Loss, PyTorch, OpenCV
- 링크: [Repo](https://github.com/cofldus/medical_image_translation) | [Portfolio](https://cofldus.github.io/)
